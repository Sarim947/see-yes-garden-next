# Pivot Door Image Set

This folder contains the Pivot Door image set generated from one source product reference.

The product design must stay consistent across every asset:

- same wood color
- same pivot door opening angle
- same vertical glass insert
- same black pull handle
- same panel line layout
- same frame proportions

## Folders

- `source/` - original reference files and reusable cutout.
- `product-card/` - `/products` card images.
- `detail-carousel/desktop/` - desktop carousel images, `1600 x 1200`, ratio `4:3`.
- `detail-carousel/mobile/` - mobile carousel images, `1260 x 1200`, ratio `1.05:1`.
- `application-scenes/` - scene-only images, `1200 x 900`, ratio `4:3`.
- `related-products/` - related product image, `930 x 600`, ratio `1.55:1`.
