# Entry Door Image Upload Folder

This folder keeps all Entry Door images grouped by where they appear on the website.

When adding a new product later, use the same pattern:

`public/images/products/product-slug/`

- `home-carousel/` - home page banner image.
- `product-card/` - product list card image on `/products`.
- `detail-carousel/` - top carousel images on the product detail page.
- `application-scenes/` - application scene cards.
- `related-products/` - related product card images.

Keep file names descriptive and numbered when order matters.
